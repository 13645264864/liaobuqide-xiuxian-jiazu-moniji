# 心魔与突破技能

本次将大境界突破改为服务端逐回合心魔战斗，客户端播放服务器保存的回合。小层突破不抽奖励。

- 心魔采用同境界同层的一品基础属性，加从练气一层开始逐次突破累计的扩脉收益，一级无扩脉，九级每次50%，中间每级6.25%。累计扩脉收益沿用对应等级的品级系数，仅乘额外增长。玩家装备不会抬高心魔强度，头像取玩家本人，不配置心魔战技或神通。
- 基础突破属性按一品境界阶梯差计算；扩脉额外增量 = 基础增量 × 扩脉比例 × 品级系数（1至1.5）。不重复乘基础属性品级系数。旧角色已有品级基础收益转换为累计收益，保持已有属性。
- 25战技、25神通共用库。大境界成功后生成持久化三选一：一至三品全战技；四/五/六品分别20/40/60%出现一张神通；七八品全标准神通；九品全强化神通。
- 已抽结果不刷新重抽，确认一次入库；同名强化不被标准覆盖。最多启用3战技、2神通；旧神识技在战技栏保留。
- 战技与神通的伤害、护盾、治疗、控制、破防、减伤、回灵、连击和条件触发由服务器结算，冷却状态保存在遭遇中。
- 普通神通跨一个境界，强化神通更强；跨两境界无跨阶加成。强度需要通过实际模拟校准，不能把卡片描述视为验证。
- 不修改地图状态RPC、地图房间或出口连接。

## 平衡验证

标准神通对高一境界持续减伤85%、每回合200%攻击反击，强化92%、400%，同类不叠加、跨两境界无效。
325组完整搭配模拟、900次中品抽样、真实自动战斗和浏览器流程通过。装备fixture为一层基础生命×1.2、灵力×1.34、攻击×1.4、防御×1.2，配基础剑术与普通战技；不是任何空装角色都保证获胜。化神以上未开放正式怪物，使用属性曲线模拟。
初版多段/召唤部分采用服务器回合聚合，敌人施法/负面状态仍待扩展，清净与免控元数据对没有此类攻击的妖兽不产生额外收益。
